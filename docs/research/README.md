# 历史研究档案

本目录保存生产方法的来源与旧版分析，便于核对证据、许可和历史判断。当前制作规则以仓库根目录的 [SKILL.md](../../SKILL.md) 及其引用为准。

[2026-11-07 研究快照](2026-11-07-snapshot/SKILL.md) 保存通用化整理前的完整skill资料。目录日期表示原研究版本，归档于2026-11-08；不是对上游仓库当前版本的核验。快照中的案例名称、提交号、源码路径、实验数值和旧制作规则只描述当时的研究材料。

普通制作不加载本档案，也不依赖原参考仓库或其角色、模型、材质和影片。需要溯源时按具体问题读取快照，并将源码事实、作者记录、运行观察和推断分开。复用实际代码或资产时仍需核对原来源与许可。

当前生产文档位于根目录references；历史快照不接收生产规则更新。

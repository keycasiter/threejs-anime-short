# 统一验收与交付检查

检查当前交付入口与对应构建，先看目标和实际画面，再查代码说明。技术能力、视觉品质、输入交互、连续动作、声音及性能分别下结论；用户只要计划/机制时仅检查该范围。记录可用项目现有格式，无固定阶段JSON要求。

## 视觉品质

| 检查面 | 具体看什么 | 失败回到哪里 |
|---|---|---|
| 全场构图与空间 | 全貌/缩略图读出焦点、尺度、前中远、负形和关键连接；每个区域有用途与层次 | 相机、空间拓扑、组团/边界与遮挡 |
| 主要可见组成 | 主体、支撑、环境及重复群体都完成对应景别；没有未完成代理或缺乏设计意图的空面 | 对应资产族/区域的代表关系与扩展 |
| 主形与中层 | 剪影、比例、体量收放、凹入、开口、厚度、承托和过渡接近目标；灰模侧背也成立 | 独立结构控制量、截面/拓扑与连接 |
| 材质与光影 | 材料身份、尺度、反射/透射与接触阴影可读；受光揭示形体，空间仍有明暗层次 | UV/通道、法线、真实环境、灯与颜色输出 |
| 动作与反馈 | 关键姿势/事件前中后及连续片段：接触、重心、从属运动与FX有因果，无明显穿插/漂移/闪烁 | 枢轴/曲面、时间/历史、接触与反馈消费者 |

同时看全幅、原尺寸近景、互补方向；动态再连续播放。风格化可以精简表面频率，同时保留目标中的结构、材料差异和空间关系。一个好看的英雄角度或局部不能代替全场检查，数量和诊断分数也不代替审图。

每个承诺视图用一句话说明观察任务和实际结论：焦点/连接是否可读，主要可见族是否达到该景别，遮挡/裁切是否有意且仍保留目标关系。覆盖记录只回答该方向是否检查；诊断特写证明细节存在，合法近景证明用户能读到。界面有标题/说明时按[模型与界面](visual-construction.md#6-近景同时设计模型与界面)查看完整页面的文字/焦点冲突。

对照固定机位、时间/状态、视口、几何/布局、曝光与非测试变量，保留首次完整代表画面和当前画面。因果判断先复取稳定基线，再只改负责当前解释的一层；实际打开对照图，记录可见收益及新增损失。

取证前等待资源、着色器与所选累积状态就绪，以及加载层/过渡真正结束；用可观察状态确认，不以ready字段或一次固定短延时推断。正式图不能残留加载色罩。保持完整页面取证，不通过隐藏产品界面冒充消除了文字冲突。

随实现使用[消费者检查代码](code-guidance.md#5-写完当前关系就读回消费者)：参数看发出的几何/矩阵/通道，动作看指定可见子件与连续片段。普通Mesh矩阵探针不覆盖shader、实例或蒙皮；对应路径另读真实buffer/姿态与画面。时钟推进、uniform变化或两个PNG不同各只证明其观察项，不扩大为全部动作通过。近远/俯仰从真实控制器读边界，普通近景与局部放大用途分别解释。

## 真实运行与相机

交互场景按[相机方法](camera-interaction.md)在最终页面实际拖转一整圈、滚轮缩放和点击复位，检查水平8方位及承诺的俯仰/远近端点。内容覆盖与控件操作分别记录；配置或静态设机位不能证明用户操作成立。记录实际设备、浏览器/后端、目标视口、质量档及一段持续帧时间/资源成本。

只保留目标页面视口；CUA/MCP、Playwright或直接CDP各按实际执行范围说明。通道不可用写具体未覆盖项，不以导出帧冒充输入操作。页面/console/shader/资源错误、空canvas和事件遮罩分层排查。

## HTML与资源包

```sh
node <skill-root>/scripts/validate_offline_html.mjs <project-root>/index.html --require-offline
```

检查脚本语法、本地资源、静态ESM导入链与简单import map；不承诺离线时去掉`--require-offline`。脚本不执行场景，计算URL/条件加载仍需真实浏览器请求和离线重载验证。返回0为静态检查通过，1为检查失败，2为输入/工具错误。

最终包包含HTML/源码、生成参数与seed、必需依赖/许可、运行说明。实际打开该包并走通主要操作，承诺离线时断网重载。生成内联脚本时用回调replacement并转义script结束标记，避免`$&`等被字符串替换解释。

## 接触粗检

有实际接触事件时，可从最终世界变换或等价变形求值导出：

```json
[{"id":"contact-01","time":2.5,"pointA":[0,2,0],"pointB":[0.12,2,0],"radiusA":0.1,"radiusB":0.03,"tolerance":0.01}]
```

```sh
node <skill-root>/scripts/check_contacts.mjs <project-root>/contacts.json
```

秒与场景单位保持一致，容差按尺度与可见误差设计。`surfaceGap=distance-radiusA-radiusB`只判断包围球接近/重叠；不能证明实际面接触或排除深穿插。配合真实表面、足迹和接触前后帧检查；没有接触事件不制造检查数据。

## 视频与交付结论

影片执行[视频导出与后验](video-export.md)，完整播放最终编码文件，查看解码关键帧、文字/细节可读性、压缩伪影、时序与尾帧；有声音再试听同步、层级、失真、底噪和结尾。编码前浏览器图不替代编码后审片。

验证记录写：当前入口/版本、目标状态、实际观察或命令结果、对应图/片段、未解决问题与负责层。修正后用当前构建复核受影响状态。发现缺陷就明确剩余差距，不以“功能完成”包装为最终高品质。交付说明区分已完成的真实检查与未覆盖范围；不把研究、机制小样或计划级遵循测试说成完整作品画质提升。

## 当前资产的缓存与真实取图

测资源稳定性时，先记录当前候选首次进入各实际渲染路径的曲线，再在同一候选上重复相同路径检查平台。新候选会退休旧材质；前一个候选已经切过look，不代表当前候选的主场景/反射捕获、形成开关和输出路径都已预热。保存首次编译的峰值和重复后的基线；几何/相机身份、资源数量和原生创建/释放分别核对。发现增长先定位消费者，不靠调高常数阈值掩盖。

匿名比较若约定只评3D画面，在真实页面收起或隐藏版本文字、工作台等覆盖层后重新取原始视口，保留操作和状态。元素截图仍可能包含叠在其上的DOM；先实际查看产物，再确认协议成立。作品本身需要的标签/界面按对应交付目标保留，不用后期涂抹替代真实运行取图。

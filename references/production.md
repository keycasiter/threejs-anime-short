# 制作技术与决策

## 建模：轮廓先于零件

涉及角色造型时，按目标问题在中性光/无后期下检查轮廓与必要正侧视角，再看最终镜头。让头身比、肩宽、胸腹、骨盆、肢体长度和角色身份成立。真人的鼻梁、颧骨、下颌应共同影响轮廓和受光；分散小球叠加可能造成玩偶感。机器人则可利用分件构造表达机械身份。

程序曲面可用超椭球控制圆/方程度，截面曲线控制长体的宽、高、腹深，局部位移形成眼窝与鳃沟。创建 UV、共享接缝法线及正确三角形朝向；给近景主角分配细节，远景细节应按屏幕尺寸淡出，避免亚像素闪烁。

人物需要极端动作时，比较分件、连续骨架蒙皮或加载符合要求的现成网格的成本。蒙皮也必须检查肩、髋、肘膝的体积保持。仅增加分段数和材质噪声不能解决比例和变形问题。

## 动作：事件和约束先于曲线

- 关键姿势：预备 → 发力 → 接触/极值 → 跟随 → 稳定；具体阶段由动作决定。
- 空间约束：接触目标、脚底支撑、手握点和道具锚点共用坐标系；用完整局部到世界变换求位置。
- FK 用于姿态设计，IK 用于保持手脚目标；脊柱、骨盆、胸腔和头部需要可独立安排的转动/滞后。
- 球/道具轨迹在接触点连续；若冲量导致速度变化，位置仍连续。接触前后的速度方向、旋转、声音应一致。
- 人体起跳需支撑、蹬地、离地、腾空和落地缓冲；整体升降加整体旋转通常不足以传递重量。

不要直接跳着给某关节角度。把每个重要角色的姿态初始化到完整默认值，再应用时间曲线；避免“只有 save 时写 rotation.z”等留下跨时间残值的分支。

主时钟使用连续秒值。有音频时优先使用音频时钟，时钟偏移在 play/seek/resume 时更新；无音频可使用 performance 时间原点。输出fps决定影片帧网格，实时刷新率决定展示机会，两者都不应逐次截断主时钟并丢失余数。

连续运动风格直接从绝对`t`求角色、相机和FX状态。明确需要抽帧风格时，才为某层配置`rate`与相位，以`phase + floor((t-phase)*rate)/rate`求该层时间；相机可继续连续取样。采样率由画风、运动速度及目标fps决定。接触/放手等cue仍按精确主时间处理，不能因抽帧错过关键事件。

## 绘画MRT分支：保持数据约定成套

仅选用绘画MRT时采用本节；PBR、烘焙或MatCap等路线按 [rendering-choices.md](rendering-choices.md) 建立各自契约。下列结构不是制作短片的必经步骤。

可选的一种分层结构：

```text
场景 → MRT：颜色 + 法线/深度/材质身份
  → 选择背景像素做绘画处理
  → 材质边界、深度跳变、法线转折处描线
  → 空气/水下透视、光柱和闪光
  → 覆盖层特效 → 泛光 → 调色、颗粒、速度线
```

适配时检查材质 ID 区间、背景/角色标记、相机法线空间、深度单位、颜色空间和 render target 精度。将普通材质直接放进自定义 MRT 渲染器可能缺少第二附件输出，必须提供兼容材质或明确回退。

赛璐珞受光同时考虑明部色、偏冷阴影、反弹光、硬高光和边缘光。保持皮肤与球衣的材质区别；不要用灯光数量替代明暗设计。提供颜色、法线、深度和身份的调试视图，排查黑块、漏描边和错误遮挡。

绘画滤波的半径与泛光模糊会增加采样成本，按目标分辨率实测。细节过远时降低法线扰动、高光和图案对比；同一团水/烟可共享轮廓策略，避免粒子逐个描边。

## 水体、雾与多遍接口

水帘与潭水尽量共享色板、流速和泡沫锚点；流纹按沿水流/横向坐标组织，避免仅叠加竖直正弦条纹。需要平面反射时镜像相机，并通过材质 pass 状态裁掉水面下内容；新增阴影/反射会增加渲染成本，应先验证代表镜头。

覆盖层雾可比较场景深度与雾片深度，在交界处逐渐透明；无深度判断的半透明片会无条件遮住前景。背景绘画半径可随深度缩小，表面细节可依像素覆盖退化。接入前提见 [渲染契约](render-contracts.md)。不同writeOut签名、pass状态、实例billboard与普通plane输入需要明确适配。

## 分镜与环境

镜头表建议字段：`id / t0 / t1 / 必须看清的事件 / 主体锚点 / 机位与运动 / 视线或表情 / 声音 / 环境响应 / 字幕位置`。最短故事也应有可感知的前因、行动与结果。

运动镜头应验证动作方向和运动物体去向。无需让所有镜头之间都做机位插值；插值中的临时构图也必须能用。特写需要值得看的脸部/材质，大远景需要尺度参照与空间层次。

球场等复杂场景按前景、主体、中景、远景建立层次。观众、波浪、草屑与投影应对应事件；例如离地物体的接触投影仍在地面，不能随物体父节点一同升高。先做好核心反馈，再增加环境密度。

字幕安全区必须包含球、脚、面部和关键道具的运动范围。使用少量必要文字；接触动作发生时不让全屏大字遮挡主体。

## 音频与导出

音效、配乐、环境轨共用 cue 表，但保持独立增益和空间处理。建立关键事件前后的动态变化；有声音交付时实际试听最终混音，不以波形或音轨存在替代。混响、EQ、压缩和限幅按目标声音选择，不把参考片的参数当通用预设。

离线文件回调注入示例：

```js
const js = bundle.replace(/<\/script/gi, '<\\/script');
const html = template.replace('/* BUNDLE_SLOT */', () => js);
```

最终 HTML 的经典脚本应再次解析；模块脚本需按模块语法校验。检查 UI 监听器绑定发生前是否抛错，WebGL/着色器是否报错，开场遮罩是否拦截点击。

实时与导出复用完整时间函数，包括标题、比分和 FX 的可见性。导出前预热所需材质，固定视口、像素比和随机种子。MP4 编码完成后用媒体信息核对帧数/时长/音轨，再检查成片关键帧和听感。

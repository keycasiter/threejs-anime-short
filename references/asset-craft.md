# 从视觉目标到资产、材质与完整场景

本页负责制作前的视觉设计与实现路线：把目标画面转成形体、结构、材料和空间的明确选择。代码配方见[Three.js实现方法](threejs-code-sop.md)，生产阶段见[主流程](production-workflow.md)，通过标准见[统一验收](validation.md)。

## 1. 建立可比较的视觉基准

视觉目标板同时回答“整体为什么成立”和“近处为什么精细”。选少量相关图，而不是收集大量题材图片。全貌看比例、主次、负形、空间层次和光区；局部看体积转折、连接、厚度、材料边界与受光；动画或自由查看增加必要姿势、侧背和遮挡关系。

| 依据 | 可以约束什么 | 不能自行证明什么 |
|---|---|---|
| 实物、尺寸/CAD、可靠多角度图 | 尺度、位置、截面、结构连接和可见表面 | 最终风格、灯光、实时成本 |
| 优秀成片/插画/3D作品 | 构图、形体组织、细节层级、材料与气氛 | 真实尺寸、完整拓扑或作者制作过程 |
| 生图/编辑设计板 | 创作方向、造型/光色候选、组件研究 | 精确背面、重复部件身份、工程/历史正确性 |
| 自绘结构/色彩稿 | 有意的体积、连接、布局和材料分配 | 已经实现的渲染品质 |

用户参考已足够时直接提炼。没有参考时自行研究或生成；方向已锁定时，内部选择视觉方案，不重复询问题材。使用主图编辑所需视角，保持比例、身份、材料和连接；并排核对漂移，冲突保留为设计未知项。图中文字和数值单独核实。

在实现前固定目标板，并写出要保留的关系与有意变化。基准应服务约定品质，不能只挑最容易复现的图，也不能把首版渲染的不足改写为风格目标。没有可见基准时准确记录未校准范围。

## 2. 先做形体与场景设计

从整体到局部确定设计，随后选择API。主角身份只是起点，还要决定它的姿态、比例、体块交接、负形、结构节奏、材料区和与环境的关系。

| 设计层 | 要做出的选择 | 落实方式 |
|---|---|---|
| 大形 | 主轴、宽高深比例、重心、剪影转折、正负形与不对称关系 | 关键截面、连续体积、空间布局、相机占幅；缩略图先读得清 |
| 中层 | 分段/分枝/装配、生长或侵蚀方向、厚度、凹入/开口、受力与连接层级 | 真正影响遮挡/阴影/受光的面与体积，父子锚点、边界过渡；不只贴浮饰 |
| 小层 | 纹样、紧固/刻记、材料颗粒、局部磨损或湿度 | 几何、顶点色、纹理/法线/粗糙度；按景别选择负责层 |
| 场景 | 焦点、支撑、尺度参照、前中远景、光区、密度与安静区 | 全场景灰盒、成组布局、接地/遮挡与可达视角覆盖 |

中层决定对象是否有内在结构。机械的装配/承载，生物的体积/关节/生长，地貌的地层/沟谷，连续介质的源头/边界/流向，各自有规律。随机缩放、均匀凹槽和重复相同体块不能替代这些选择；有意的简化须保留目标画风中有价值的关系。

对未确定且影响上限的设计，用低成本可见方案比较：草图比较轮廓/负形，灰盒比较体积/布局，局部样件比较构造/材料。一次改变关键变量，按目标选择；不要求每个已定零件都做候选。不要默认沿用第一种可编码形状。

## 3. 按品质风险选择表示

| 目标需求 | 可用路线 | 最先验证的风险 |
|---|---|---|
| 壳体、容器、回转/装配件 | 截面回转/挤出/扫掠、带厚度与孔洞的组件 | 内外壁、端口、倒角/折脊、搭接与侧背厚度 |
| 不规则有机体 | 连续参数网格、体积/雕刻场、按结构融合的体块；或修整模型 | 全方位体积、连续曲率、负形和关键转折；正面轮廓挤出可能成为薄板 |
| 角色/柔性物体 | 连续网格、骨骼/脊柱、权重和修形 | 极限姿势的体积、法线、穿插及变形后锚点；刚性拼件不自动成为皮肤 |
| 分枝/承载/重复群体 | 曲线骨架与变截面、结构族、受控实例布局 | 真实连接、主次收分、空间相关变化、重复节奏与容量 |
| 地表/布/连续水体 | 曲面、位移网格、共享高度/速度场 | 表面连续性、法线、边界和流向；倒扣/洞穴不能用单值高度场硬凑 |
| 精细且复杂的独特资产 | 程序网格、DCC或许可模型/AI候选修整、混合路线 | 关键轮廓/结构、UV/材料和动作先验，来源/许可及运行成本 |
| 只改变表面信息 | rest/UV/局部程序纹理、法线/粗糙度、shader | 不改变轮廓、厚度或真实接触；固定纹样不得随世界噪声漂移 |

分别记录**构造来源**与**运行表示**：规则生成、测量/扫描网格、导入模型、图片和动作数据说明细节从哪里来；GLB、压缩数组、原生JS模块说明如何传输与还原。把源网格/纹理编码进代码不会变成独立程序造型。允许资产时保留有价值的UV、材料和骨骼，再适配单位、支点与动作；纯代码约束下选择可从设计参数重建的几何规则，不能把原图投影或隐藏数据包当作建模能力。来源与许可随实际数据保留。

涉及回转壳体、内腔、贯穿孔或倒角板件时，开工前读取[截面与厚壁方法](profile-geometry.md)，按其支持范围比较已验证生成器与原生/自建表示；选定后把实际消费者写入资产接口。

选择后先实现最困难的部位或视角；验证局部与全场景的关系，再扩展。代码纯生成约束下，换参数曲面/拓扑/分件策略；允许模型资产时可改资产路线。反复增加细分、噪声与后期而轮廓/中层仍失败，说明表示或设计需要重开。

## 4. 把设计交给实现

为焦点与主要环境组成保留短映射；重复资产按族记录，无须为每个微小对象写文档。把关键可计算关系落实为截面、路径、锚点、材料区和取景参数，追到生成/渲染代码的实际读值位置。只写进台账、字段名或`userData`的特征还没有成为画面；需要明确实现消费者，再用当前局部图确认表达。

| 字段 | 要表达的内容 |
|---|---|
| 目标视觉关系 | 目标板的具体部位/视角；主形、中层、材料或环境关系 |
| 选定设计 | 比例/截面、体积交接、层级、厚度/负形、材料分区；与参考的有意变化 |
| 实现责任 | 参数由哪个生成器/模型/材质/布局实际消费；单位、坐标、父级、锚点、变形与边界 |
| 细节预算 | 最近/典型/最远景别的像素尺寸、资源上限、可合并/省略的信息 |
| 可见证明 | 正/侧/背/灰模/局部或关键时间；当前构建与目标的实际差距 |

世界单位与原点保持稳定。真实场景先把地图/正交位置和目标照片的屏幕遮挡分开约束；未知位置与背面明确为估计或设定。重复变化由形态族、范围、权重和空间规则产生，固定seed；实例容量由计划求和，不能静默截断。

细节预算按投影分配。近景焦点承担有身份的体积与连接、材料受光；中景保留主要结构分组和遮挡节奏；远景保留轮廓族、色带和大气层次。约低于2px的信息通常合并为材料/簇而非独立高对比几何；阈值由画风、采样和运动复核。

## 5. 设计材料与光影，不只填写PBR数值

先决定材料各自靠什么响应被辨认：金属的反射带/边缘、粗糙材料的宽明暗、薄层/湿面的高光和透光等。再把颜色、粗糙度、法线、透射和光源落实；同一材质也应有功能区域与形成逻辑，避免全物体同一响应。

- 轮廓、厚度和真实凹陷由几何负责；albedo只能改变色斑，光照法线改变局部受光。
- 主光揭示主要体积，填光保留结构，环境反射形成有设计的宽窄亮带；检查明暗边界与高光是否吞掉中层。风格化可使用受控色阶，不要求写实PBR。
- 表面变化按大/中/小尺度和材料形成方式组织。磨损/潮湿/纹理方向落在相应功能区域；安静面保留呼吸，避免均匀高频脏噪。
- 坐标、UV、颜色空间和输出转换遵守[渲染选择](rendering-choices.md)及适用的[渲染契约](render-contracts.md)。材质存在不证明最终像素呈现了预期效果。

制作程序表面、划痕/木纹/织纹或粗糙/法线数据前，读取[表面细节方法](surface-detail.md)，先写形成规律、坐标和尺度，再选择字段与实际shader通道；已有资产贴图则核对其语义和消费者。

## 6. 校准代表画面

固定目标图、相机/景别、种子与尺寸，把当前画面并排。先按画面本身判断，再读代码解释：

| 判断 | 看的证据 | 不足时回到哪里 |
|---|---|---|
| 身份与完整性 | 缩略剪影、完整场景、侧背/包络 | 大形、布局与范围 |
| 结构与体积品质 | 真灰模、掠射光、原尺寸关键局部 | 体积转折、中层、连接/负形和表示 |
| 材料与光色品质 | 最终材质原图、必要开关对照 | 材料区、光区、反射带、坐标/输出 |
| 空间与整体品质 | 全景及目标机位序列 | 主次、纵深、尺度、环境完成度 |
| 时间稳定性 | 邻近时刻、连续片段与乱序seek | 姿态、锚点、采样、数据/历史状态 |

记录最影响目标的实际差距，不用“可辨认”替代“达到目标层次”。修复有可见结果后再放行；独立或单独一轮审阅均按[统一标准](validation.md#核心镜头放行标准)记录范围。技术完整、画面品质、交互与交付分别形成结论。

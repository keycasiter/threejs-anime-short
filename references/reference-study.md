## 参考片为何像成片

接触表可见：大场景、角色近景、动作远景、眼部特写和反应镜头形成尺度变化；蓝紫环境、暖色角色与白色水花建立视觉层次。源码进一步表明，动作、环境反馈、表情和镜头围绕同一组 cue 组织。新短片应继承这种联动关系，而非仅模仿文件名和滤镜。

建议阅读顺序：`README` / `PLAYBOOK` / 接触表 → `shots` / `director` → `engine` / `glsl` / `materials` → 与新角色类型相符的模型文件 → `fx` / 环境 → `audio` / `player` → 构建与验收工具。

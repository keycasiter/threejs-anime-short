# 群体分布、附着与细节尺度

在正式形态原型已有代表关系后扩展群体。输入是共享区域/宿主/路径、原型工厂与seed；输出是实际接受的唯一一批摆放数据及其网格。材料与受光从代表件延续，不推迟到批量完成才处理。

## 1. 先确定细节要改变的画面关系

只把会影响目标图的细节纳入本阶段。逐项读取视觉特征，说明细节出现在哪里、形成什么节奏、在多远处需要可见，以及什么区域必须保持开放。可表达的目标包括：轮廓断续、结构节奏、尺度参照、局部聚集、表面覆盖、功能标识或环境反馈。不要把“增加数量”当成目标。

一个分布组对应同一类资产/效果、同一分布方法和一组可复核目标区。将共享布局中的允许区、宿主面、洞口/路线净空、相邻群组和视觉特征ID写入计划。面状宿主用准确的边界多边形及孔洞；仅有surface AABB时不能把整个盒子当作合法散布区。体积粒子或云雾可用明确的三维包络，但仍需单独标出要保留的通道、焦点和稀疏区。

## 2. 按空间拓扑选生成方式

| 空间关系 | 首选方式 | 不适合的方式 |
|---|---|---|
| 建筑构件、铺装、窗格等规则节奏 | 轴网/模块阵列，按边界与开口裁切 | 全局随机散点 |
| 植被、碎石、珊瑚等有聚集/生境差异的群体 | 先采簇中心，再在簇内采成员；由高度、坡度、湿度、朝向或邻近关系调节权重 | 在整张场地均匀取样后只靠拒绝采样补形 |
| 沿岸线、道路、枝干、裂缝等连续结构 | 沿实际曲线/骨架按弧长采样，再施加受限横向偏移 | 对控制点插值后直接按世界XYZ等距撒点 |
| 局部雕饰、焦点道具或需要确定构图的元素 | 手工落位，必要时以程序生成可控变体 | 为了省事强行程序化所有资产 |
| 雾、雨、火花、气泡等三维群体 | 在明确体积/发射器域内分层或按流场采样 | 用地面二维分布掩盖深度与流向 |

随机只负责同一组内部的变化。先安排大组的位置、边界、方向和留白，再生成组内实例；固定seed，位置、尺度、朝向、变体之间按生境/构造逻辑关联。`variantId`引用已经实际制作/检查的形态原型；位置、缩放、旋转和颜色/表面随机另存为实例参数或材质参数，不据此增加形态变体数。缩放范围若会明显改变资产的主次比例或剪影，应登记为单独几何原型。人工控制的焦点实例保留明确稳定ID，不能被随机流程移走。

具体生长、冠层、岩块和最小间距/变密度算法读[分枝与散布配方](algorithm-recipes.md#分枝冠层与受约束散布)。先用形成规则定义真实原型和生境，再用Poisson等采点；点数与间距合格不代表形体丰富或构图成立。

## 3. 让生成器输出可核对的真实结果

Three.js中先生成候选，再按顺序做合法性筛选：允许区/孔洞 → 功能净空 → 最小间距/相交 → 宿主面命中与高度 → 朝向/尺度/变体。记录候选数、实际接受数和按原因统计的拒绝数；三者必须能相加核对。固定次数拒绝采样容易使目标区实际密度低于计划，若拒绝率过高，改用域内采样、分区采样或路径参数采样，不要静默缩减实例。

每个最终实例保存稳定`id`、`zoneId`、来自实际原型目录的`variantId`、世界锚点和尺度；锚点是对象落地/附着点，不是未说明的包围盒中心。`InstancedMesh`可用于同拓扑、变换简单且共享材质的族，但实例矩阵必须从同一份放置数据生成。保存的放置数据、运行网格和诊断图需来自同一build与同一seed。宿主采样使用最终曲面或明确surface ID；高坡度、悬挑、多层地面和洞顶不能由单一`heightAt(x,z)`猜测。大量放置可用数组、JSON或CSV保存，生成网格与诊断图共用同一批结果。

按真实连接方式检查附着足迹：根部、底座或各支脚需要支承，冠层/挑出部分可以悬空。中心点命中不证明整块基部成立；分布允许区也可能延伸到宿主之外。候选落位先满足允许区与实际可附着区域，再检查足迹边缘；边缘落空时移动、缩小或改附着方式，并保存计划位置、实际位置及修正原因。修正后重新核验受影响的允许区、净空、间距、原型尺度和支承，不继承修正前的通过结论。不能用延长根柱或把未命中的高度设为零掩盖无支承。

```js
const placements = buildPlacementPlan({
  zones, exclusions, hostSurface, densityField,
  familyVariants, seed: fixedSeed,
});

for (const item of placements) {
  // 运行网格与诊断图共用相同的item，不各自重新随机一次。
  const host = sampleActualHost(item.positionXZ, item.hostSurfaceId);
  item.anchorWorld = host.point;
  item.normalWorld = host.normal;
  item.variantId = chooseVariant(item.familyId, item.id, item.seed);
}
placeInstances(placements);
writePlacementReport(placements, generationStats, seed); // QA侧导出，不把HUD/调试线放入最终画面
```

这是结构示意，`buildPlacementPlan`等不是Three.js API。具体分布函数应能从视觉特征回溯到生成参数，再追到放置数据和实际网格/实例。仅有源代码、count或`userData`标签不能证明该实例被绘制。

### 分开附着基部与主体方向

这部分可在完整代表关系构造时使用；数量扩展仍在已批准原型之后进行。先从实际基部几何取得足迹周界、边中点和内部样本，再从候选位置的实际表面建立局部参考平面。把射线范围、允许偏离和法线变化按基部厚度、表面尺度与目标近景的可见误差设为设计输入。

复制[表面锚点模块](../assets/scene/surface-anchors.mjs)，使用同一场景的THREE创建可重复调用的资格采样器。下列变量来自当前基部规格，所有距离为世界单位；`footprint`是参考架局部XZ的偏移，不是另一份世界坐标表：

```js
const qualify = createSurfacePatchSampler(THREE, actualHost);
const patch = qualify({
  origin: candidatePoint, normal: attachmentNormal,
  footprint: baseOffsetsXZ,
  above: rayAbove, below: rayBelow,
  maxOffset: baseOffsetLimit, maxNormalAngleDeg: normalLimitDeg,
});
```

函数沿参考法线使用有限射线，检查最先露出的真实表面，返回`ACCEPT/REJECT`、具体原因、实际接触点与法线、最大偏离及`frame.matrix`；实例和父级变换由底层采样器处理。它资格检查给定的离散足迹，不拟合平面或生成基部。先用周界与少量内部点筛选，再按表面特征尺度加密；跨层、漏点或方向不一致时换候选/构造方式，不选择更深的隐藏表面来贴近参考平面。

| 构造层 | Three.js实现与交接 |
|---|---|
| 附着基部 | 用实际接触点转入`frame.matrix`的局部空间，构造有有限厚度的底面、上表面及边界连接；曲面基部可用有序径向网格，台阶/倒扣按真实接触选择分件或实体裁切。形变量受基部自身预算约束 |
| 主体与功能方向 | 主体使用独立的生长、重力或安装坐标架；是否跟随表面法线由设计决定。需要直立的枝干/设备保持其方向，只有基部负责接触适配；壁挂件也可明确选择与基部相同的方向。父级有变换时分别用其逆矩阵转换世界架 |
| 连接与复核 | 基部顶部与主体接点保留真实搭接/连接；发出网格后独立测底面顶点、边中点或三角内部点，并检查实际基部的厚度、比例和主体剪影。接触修正后重验允许区、间距与净空，近景和互补视角同时查看基部与主体 |

保持主体几何或记录有意的结构变化，避免把整棵、整簇或整个安装件逐点拉到地面。接触间隙通过仍可能留下细长底柱或不合理接头，需回到有限基部及主体关系重设计。

## 4. 先看分布图，再看真实Three.js画面

批量扩展前先对每个组生成同坐标范围的诊断图：允许区、排除区、候选点、接受点、目标分区计数/密度和宿主面。诊断图用于找空区、偏区、边界泄漏和采样偏差；不替代最终场景图。按目标分辨率捕获三个互补画面：

1. **context**：整组在完整场景中的占幅、焦点让位、前中远关系与实际空白。
2. **distribution-map**：组域、孔洞/净空、分区目标与实际放置点。色标/符号可读，坐标方向和比例尺明确。
3. **detail**：代表近景显示实例形态族、尺度变化、间距与真实接地/连接；不能仅用无材质点云。

再结合最终相机包络检查近、中、远屏幕尺度：投影尺寸足够时保留结构细节，进入次要景别时让细节合并为群体轮廓、色带或稀疏纹理。高频内容低于目标采样尺度时降低对比/密度或合并表示，避免远景变成均匀噪点；焦点资产可保留更细变化。任何像素阈值、计数范围和密度曲线都由当前参考、对象尺度、视口及相机域推导，不照抄通用常数。

## 5. 从结果定位分布问题

| 观察 | 改动责任 |
|---|---|
| 缺区、偏区或不属于当前场地 | 区域/宿主边界、簇尺度、候选与接受统计 |
| 机械等距或白噪声 | 轴网/簇中心/路径参数与组内变化，先改大组关系 |
| 同形重复或随机失去身份 | 真实形态原型、权重与使用条件；有意统一则调组间节奏 |
| 远景噪点或挡住焦点 | 投影尺寸、密度/对比、近中远表示与保留空隙 |
| 悬空、侵入路径或接头失真 | 完整足迹、最终宿主、允许区/净空和基部构造 |

数值通过后还要在完整上下文、代表近景和互补方向审图。修改位置、尺度或基部后重验受影响的支撑、允许区与净空；诊断图只解释数据分布，最终质量按[统一验收](validation.md)。

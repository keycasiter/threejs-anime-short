# 程序化造型、运动与环境机制

用于把新题材的结构规格落实成可控生成器。按目标选择机制，基础库可正常使用；不要求采用特定作品的函数名、数值、角色或源码。设计输入见 [资产设计](asset-craft.md)，材质输出见 [渲染契约](render-contracts.md)。

## 造型：连续主形、局部结构与真实厚度

| 结构需求 | 生成方式 | 必要输入/检查 |
|---|---|---|
| 壳体、船体、长体 | 沿主轴取截面，宽度/背高/腹深各自插值，连接成网格 | 关键比例、截面形状、闭合端盖、法线/朝向、近景曲率 |
| 自然体积 | 基体加具有方向和尺度的局部雕刻/位移 | 隆起/凹陷对应形成逻辑，轮廓、侧厚和遮挡成立 |
| 装甲/面板/外壳 | 连续基体上铺有厚度、倒角或折脊的板片 | 使用主体表面/法线定位；连接、间隙、覆盖关系有理由 |
| 回转结构 | 半径—高度曲线绕轴生成 | 平滑收分/台阶、内外壁与开口厚度；不能只做外观贴片 |
| 标识/表面细节 | 自产图集、局部投影、贴图或shader | 不替代轮廓、孔洞和受力结构，纹理密度与目标像素匹配 |

截面曲线可以分别控制左右宽、上/下半高与中心偏移；局部位移修改真实顶点，图案修改颜色，凹凸修改受光。生成参数要追到顶点/法线/材质的实际使用，不把未消费的bevel参数当成已倒角。

闭合UV接缝可保留重复顶点但需平均相应法线；半径归零的收口各角度必须同位置。检查顶点有限、三角形朝向、退化面与端盖。密度按曲率和最近景别分配，顶点多不能替代设计。

非均匀缩放要用逆转置矩阵变换法线；实例变换也需计入。几何法线、照明凹凸法线、描线法线和阴影偏移各有职责，高频凹凸不必全部进入墨线。

## 运动：姿势与约束

分件角色可用FK安排主姿势、两骨IK保持端点。肩/髋S到目标H的距离L、两段长度a/b给出：

```text
x = (a² - b² + L²)/(2L)
h = sqrt(max(0,a²-x²))
关节 = S + 指向目标的单位向量*x + 垂直pole方向*h
```

限制可达距离，处理零距离、pole平行和极限伸展退化。IK不自动产生重量；支撑相、重心、预备/发力/收势与躯干/头部滞后需要设计。精确接触cue不因分层抽帧而延迟。

长体可在静止空间建一次曲面，再沿脊柱变形。沿弧长采样中心与局部坐标架，处理切线/法向平行、坐标架翻转和端点外延；四元数插值前保持同半球。顶点按轴向参数映射到变形后位置，附属物和CPU锚点采用一致关系。

GPU形变的表面查询需覆盖实际缩放、颌/关节权重和额外摆动，不能只镜像中心线。检查极限姿势、接触前中后和随机seek；数值一致仍需观察真实表面。

## 表面坐标与细节层级

| 坐标 | 用途与边界 |
|---|---|
| rest/UV | 固定在皮肤、衣物上的花纹和旧化，随变形附着 |
| object/local | 独立物件的面板与局部细节，注意父级缩放 |
| world | 跨物体环境场、风雪/雾；不默认用于移动物体固定花纹 |
| flow | 流体沿流向/横向的米制坐标和速度 |
| screen/derivative | 描绘强度、像素尺度退场；处理时间稳定性 |

可用`mpp=max(length(dFdx(P)),length(dFdy(P)))`估计每像素表面尺度，分层淡出花纹、凹凸和高光。阈值由对象实际单位、频率和输出分辨率确定，不复制大尺度场景参数到小物体。

## 环境：共享结构与反馈

云塔等团块体积先建立整体轮廓和明暗，再添加局部细节。每个球各自强打光容易暴露重复形状；仅统一颜色又会变成平片。整体受光、局部法线、厚度/遮挡和背景层次共同判断。

连续水面和物体的交界由同一高度场/变形表面求解。例如采样链跨越水位的相邻点可插值得到交界，喷发/泡沫从交界派生；踩地、握持、碰撞也依赖实际接触。环境响应按大块体积、贴身薄层、碎屑/水滴、雾和表面痕迹选择不同表示，再共享色板、时间和锚点。

水帘像纸片、条码或水滴像黑边鸡蛋时，先查曲面厚度/方向、流纹频率、轮廓分组、法线和光响应，不靠堆粒子隐藏。细化只保留目标景别能读到的变化，远处波纹与高光也须抗闪烁。

固定部件按关节/材质/属性布局合批，重复元素用适合的实例方案；保留独立更新对象和资源归属。复杂度预算包括全部阴影/反射/后期，不由最后一次render的统计代表整帧。更多状态/规模边界见 [动画与场景规模](motion-and-scale.md)。

# 把视觉目标变成可生成设计

用于补全短需求、分析视觉参考、设计对象族和制定构造输入。制作顺序见[生产流程](production-workflow.md)；空间和相机见[场景布局](scene-layout.md)，形体实现见[构造配方](procedural-construction.md)。

## 1. 先设计观众要看见的关系

继承用户已确定的主题、风格、范围和交付方式；能自行核对的事实先查证，创作空缺由执行者做明确设定。只有会实质改变作品目标的冲突才需询问。方向开放时提供有实质差异的视觉方案；用户已选择或授权自行决定时，直接完成设计。

| 设计项 | 转成可实施输入 |
|---|---|
| 观看任务 | 影片、环绕或漫游；最近观察距离、全貌范围、目标视口、允许操作与交付平台 |
| 完整空间 | 场地边界、主要区域、高差、承托、路线、邻接关系与远景；包含会被观察的侧背 |
| 尺度 | 世界单位、主要对象尺寸、关键截面、相邻尺度参照；来源尺寸和设计尺寸分开 |
| 造型语言 | 主轴、轮廓族、实与空、分段、对称性、转折、收分和连接方式 |
| 画面责任 | 全貌读方向和主次，区域读用途与密度，近景读结构、连接和材料 |
| 动态与成本 | 主动作、接触反馈、静动边界、目标设备及起始预算 |

把“精细、宁静、厚重、潮湿”等词转成可观察的信号，并指明出现位置。例如静谧可由大片安静面、有限光区反差和低频动作共同表达；厚重可由截面、口沿、接触与受光带表达。每个关键词选择决定画面的主信号，避免同时堆叠互相抵消的效果。

## 2. 用参考解决具体未知

先看全场，再逐层看每个主要区域、对象族、关键部件、连接和表面。参考图数量不设上限，也不能以一句短需求或一张全景图代替拆解；短需求由Agent补成覆盖充分的参考集，不把搜集责任退回给用户。持续补充到每个主要可见关系都有图像证据或明确设计决定，未知项也有记录。

### 参考收集SOP：宏观到组成细节

先为场景建立对象树，再按对象树逐层补图。每一层都覆盖整体关系、局部结构和互相连接；需要自由环绕的成品还要覆盖会被360°观察暴露的侧面、背面、顶部和低视角。视角、距离、高度或俯仰能解决不同疑问时分别取图，不强求固定张数，也不把同一张图重复登记为多种证据。

| 层级 | 必须收集/生成的视图 | 逐图要确认的内容 |
|---|---|---|
| 宏观全场 | 多个方位与远近的全景；高位/低位、俯视/平视等能解释空间的角度；总平面或轴测图；必要的地形/建筑剖面 | 场地边界、主要体量、前中远层、焦点、地平线、入口、路径、留白、组团和后侧空间如何相连 |
| 功能区域 | 每个主要区域的全貌、与相邻区的过渡/连接、从主路径观察的视图；复杂或有高差的区域补剖面 | 区域用途、边界、层级、尺寸、相互遮挡、穿越/停留关系以及必要承托 |
| 主要资产/对象族 | 每种决定身份的原型取整体正/侧/斜视；补背面、顶面、底部或尺度参照，直到外轮廓和体量可解释 | 主轴、比例、截面变化、开口、实空关系、与同族/环境对象的尺寸对照及允许变化 |
| 组成部件与连接 | 对承重/支撑/附属/活动部件分别取能看清接合的近景；对关键位置补正视、侧视或剖面细图 | 部件边界、实际厚度、转折、搭接/嵌入、端口、接触方式、净空与连接顺序 |
| 表面与材光 | 关键材料的近景、掠视/反射角、亮暗环境和接触边；有方向性的纹理/形成另加方向参照 | 纹理尺度与方向、高光宽度、反射来源、凹槽/边缘响应、磨损/湿度范围及光源动机 |
| 用户声明的观察范围 | 影片按镜头与动作段取图；交互/漫游按完整目标范围补图，尤其检查易隐藏的背侧、顶部、底部和转角 | 该交付方式实际会看见什么，哪些表面/连接不能省略；不要用固定机位插画证明自由环绕完整性 |

将所有图整理成一份可追溯的参考板。每张图记录：稳定对象/部件ID、视向与景别、证据来源、它回答的结构/空间/材光问题、已确认的尺度或比例、对应的生成输入、可信状态（观察到/推断/设计/未知）及尚未解决项。原始图、局部放大和标注图分别保留身份；细节看不清时另补局部图，不从低清全景猜接口。

实际照片/测量资料优先限定事实尺寸和构造；优秀作品限定希望达到的构图、层次、材质或表面信号；AI生成图用于提出候选形制和补足未定视角，不能自动成为实物证据。不同参考互相矛盾时，先选择一个连贯设计并记录取舍，再把选定的尺寸、朝向、连接和材光约束交给下游；禁止把几张不同身份/比例的图拼成互不相容的模型。

视觉分析交付给空间搭建时，每个主要对象至少带着唯一ID、所属区域、场景位置/朝向、占地与高度、支撑/接口、邻接和遮挡关系、参考视图编号、证据状态及未知项。空间搭建据此做总平/剖面和白模；中层形体据对象与部件参考补真实截面、厚度和连接；细节分布与材光继续引用同一参考ID，防止尺度、材料和结构身份在模块接力时丢失。

**完成条件：** 场景范围、每个主要区域、每个身份关键资产及其关键组成部件都已被纳入参考板；其轮廓、体量、接面、支撑、观察面和材光线索能追到图像或明确的设计决定。仍未知的细节须标作设计项并选定方案后再进入建模，不能因输入简短而静默省略。

| 参考来源 | 适合约束的内容 | 使用边界 |
|---|---|---|
| 实物、可靠多角度照片、尺寸图、地图或测量资料 | 位置、尺度、截面、构造和可见表面 | 单张透视不能给出唯一三维形状或精确尺寸 |
| 优秀成片、插画和实时作品 | 构图、形体组织、材光和运动节奏 | 可见成品不能证明作者的制作过程或隐藏拓扑 |
| 生成式设计图 | 创作方向、候选形制、光色和材料研究 | 多视图的身份、数量、比例和连接仍需核对；隐藏构造属于设计 |
| 自绘结构、平面、剖面或色彩稿 | 有意的空间、截面、连接和材料分配 | 设计输入还需在真实运行画面中实现 |

每张有用参考记录来源、视向、覆盖范围、解决的问题、对应对象及仍不确定的部分。事实状态可简写为“观察到／推断／设计／未知”，附在具体尺寸或关系旁。

### 从全貌到接口的参考组合

| 视图 | 需要回答的问题 |
|---|---|
| 不同方位/高度的全貌 | 主体与环境的体量、前中远层、地平线、主要空隙和遮挡如何组织？ |
| 平面、轴测或总图 | 占地、朝向、间距、路线、区域边界及英雄机位后方有什么？ |
| 立面与地形剖面 | 高程、厚度、悬挑、嵌入、承托、净空和地形转折如何成立？ |
| 主要对象完整侧背 | 它是独立、附着、嵌套、开放还是封闭；哪些轮廓决定身份？ |
| 接口与材料近景 | 哪些面相接、如何转折、壁厚多少、纹理方向和反射带在哪里？ |

需要生成补充设计图时，以选定主设计为视觉锚点，保持身份、比例、材料与连接，仅改变视角或研究部位。接触表会使细节不可读时，分成单独图像。将冲突解决为一个选定设计，剩余未知明确标出。

### 用现有渲染研究增强，再回写三维

已有草案需要提高形制或材光时，保留真实相机、布局和源码，用不含操作界面的当前渲染约束设计候选。

1. 固定当前空间，只描述需要研究的局部结构或材光；核对候选是否改变透视、对象数量或接触。
2. 把新增信息分为轮廓/孔洞/连接、表面区域、光源/反射；无法由输入确定的构造记为设计选择。
3. 体积差异写入截面、拓扑或控制网格；表面差异写入程序材料场；光影差异写入真实灯和环境。基础色表达材料本色，镜头相关高光与阴影由渲染产生。
4. 用相同机位重渲染，再看暴露厚度、背面和连接的方向，确认运行资产已产生目标关系。

## 3. 建立统一坐标与空间图

选定单位、上方向、原点和对象局部前向，贯穿布局、图纸、几何与锚点。示例约定可以是米、+Y向上、XZ为平面；真实场地另记录地理坐标到场景坐标的转换和高程基准。

从“场地→区域→主要对象→子装配→接口”分解；小作品可省略不需要的层级。每个主要对象明确位置基准、朝向、尺寸/轮廓、宿主、接触部位、关键端口和观看方向。连接写成具体对象对及其用途，如“步道末端接入口平台”，同时给两端与连接段。

### 图纸区分不同空间含义

| 几何含义 | 图纸和实现中保存什么 |
|---|---|
| 保守包围范围 | 对象可能延伸到的整体边界；另给实际落位基准 |
| 实际占用 | 平面实体及孔洞；围院、环形开口等保留真实空区 |
| 承载/接触 | 脚垫、基础、安装面、支点或连续承托段 |
| 通行 | 路面/平台的有效边界、宽度、转弯、净高与落地接口 |
| 悬挑与分布/净空范围 | 屋檐、树冠、允许散布域、观察或运动通道；各自使用不同图例 |

把包围盒中心、落地锚点和接口点分别命名；屋檐投影不能作为整块可行走地面，树冠范围也不应发射为实心体。

从同一布局数据生成平面和必要剖面。平面显示区域、轮廓、路线、接口与图例；剖面穿过决定高差、支撑、洞口或路径坡度的关系。复杂地形或长路线沿变化增补断面，简单平地只画有用关系。

CAD/GIS用于可靠尺寸与边界时，注明来源、比例、轴向和高程转换；创作场地可直接生成SVG等设计图。图纸标明实测、估计或设计尺寸，并以实际阅读尺寸查看：线型、标注和高程清楚，端点位于真正的落地/承载区域。图纸与运行几何共用输入，避免各自抄坐标。

## 4. 先设计形态族，再生成实例

盘点焦点、支撑、边界、主要环境组和远景，把结构相同且参数可变的对象归族。每族定义决定身份的不变量、结构原型、可变尺寸与从属关系。

| 变化层 | 实际改变什么 | 适合的控制 |
|---|---|---|
| 结构原型 | 剪影、体块分组、截面、开口、分枝或连接形式 | 独立生成参数/拓扑；同尺度灰材质和互补视角比较 |
| 实例变化 | 同原型允许的尺寸、位置、有限朝向、间距 | 区域权重、范围、稳定对象ID和局部种子 |
| 表面变化 | 颜色、粗糙度、湿度、磨损等材料信号 | 形成区域、方向与有界材料参数 |

例如树族可设计直立分层冠与横展分枝冠；建筑族可设计长体双坡与围合带孔体。它们展示结构差异的类型，具体原型由当前题材决定。设计要求统一时保持统一，由组间节奏、密度和材光组织变化。

先在目标像素尺寸下比较各原型的真实剪影、体量和负形；差异仅靠颜色或整体缩放时，继续设计结构或合并原型。然后完成一个带相邻支撑、材料和受光的代表关系，再按[构造配方](procedural-construction.md)扩展工厂。

## 5. 把特征交给真实构造

主要可见特征沿“**参考观察→设计约束→表示/参数→实际消费者→目标视图**”落地。一行足以说清的关系保持一行；连续体、装配和动态分别选择对应生成方式。

| 目标特征 | 需要的设计输入 | 实现与观察 |
|---|---|---|
| 有身份的剪影与转折 | 主轴、关键截面站位、宽深、收分、偏心和端部 | 参数生成真实顶点；全貌和侧背看体量 |
| 厚度、凹入与孔洞 | 内外边界、层距、洞深、口沿和需要贯穿的层 | 壳/带孔挤出/专用拓扑；斜侧能读厚度与空隙 |
| 连续过渡或装配 | 转折前后邻域、局部接口、融合/搭接范围、枢轴 | 完整生成相邻体积；连宿主取景，尺寸改变后接触随动 |
| 材料差异 | 材料区、形成原因、米制尺度和方向 | 共源区域进入需要的颜色/roughness/metalness/normal通道；在实际曲面看响应 |
| 局部光区与透视层 | 接收面面积/朝向、灯位置、遮挡、窗后内容及相机 | 接收面、灯、环境/透明路径实际接通；近景和上下文共同判断 |
| 动作与反馈 | 时间/事件、静动层级、变形边界和接触部位 | 枢轴/骨架/曲面求值后派生锚点；关键状态与连续运动检查 |

例如深窗洞由开孔墙壳、洞壁、框和后退窗面共同产生；洞宽高与墙厚输入顶点生成，安装面从同一局部框架派生。若函数尚未编写，明确其输入/输出并标为待实现；用实际函数名和消费点替换示意接口后再判断效果。

## 6. 交给实施的最小设计

保留可直接使用的内容：一份完整范围/尺度/观看任务的简明brief；统一布局与关键关系；解决结构和材光未知的参考；主要族的原型和尺寸控制；特征到生成器/消费者/视图的映射。形式可为JS对象、表格、图和短说明，服从项目规模。

对现有作品，区分用户或事实锁定的尺度/接口/通行范围与可重新设计的形体。代理传递空间意图；正式曲面改变后，支撑、附件、表面路线和落点从最终宿主重新求解。记录受影响的消费者与回看方向，保持同一数据源。

设计完成时应能开始制作一个完整代表关系：选择的表示能表达目标特征，关键尺寸有来源或设定，必要视图能揭示差异。最终品质与交付范围由[验收](validation.md)对当前运行作品判断。

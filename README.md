# Three.js 视觉作品制作 Skill

将视觉目标落实为Three.js资产、完整场景、材质、摄影、动画与交互，交付可运行代码、HTML或视频。生图默认用于设计参考，最终场景由Three.js渲染。

## 当前方向与入口

`master`保留优化基线，原`main`历史保留。`codex/saltline-production-systems`采用代码生成几何、程序表面与Three.js渲染，分支不自动合并。

### 2026-11-13｜R95 受约束地形与道路共形接力

依据：R94已提供受限共形三角地形的道路消费者，但没有通用生成器。为避免顺序叠加局部高度后旧路失去原支承，新增从已验证规则高度网格出发的通用约束细分能力。

变更：新增`createConstrainedTerrainGeometry`与[约束地形方法](references/constrained-terrain.md)，以凸XZ域分割原三角，插入约束边，做源面重心插值与全局共边点修复；`heightAt`可采样生成新高度，保护区保持原分片地表；凸域空间候选、边测试和共形修复共用有界工作预算，输出顶点/三角独立限额。地形结果作为明确`triangulated`输入接到现有道路消费者；同时修复道路消费端把空间查询分桶误当作真实地形吸附轴的问题。更新主入口、工具目录、核心系统和道路方法页。非规则初始网格、凹域自动分解、桥洞/多值地形及整地设计求解不在此模块范围。

验证：r187最终完整套件796项，受限浏览器环境778通过、18个Chrome启动失败；同版正常启动权限下`render_film.test.mjs`18/18通过，合并796/796无跳过。地形/道路专项31/31；新文档示例原文执行成功。Skill格式、三文件语法、差异检查与六份文档184处本地链接通过。验证和C1接入范围见[记录](../threejs-spatial-capability-r95/验证记录.md)。该模块尚未接入`core-world`或冻结C1完整场景，尚未证明原道路全覆盖保形或整场画质提升。

### 2026-11-13｜为既有道路支承增加受限共形三角输入

依据：S04 C1完整世界前置核对发现，局部场地要细分地形时，当前道路支承只消费规则XZ网格；未经约束叠加高度场会改变已生成旧路。新增路径针对通用几何输入能力，不生成场地、不改变旧网格默认行为。

变更：`prepareTerrainRoadSupport`新增显式`topology: 'triangulated'`，为唯一高度的完整矩形共形三角面建立有界XZ索引，并验证上向绕序、完整边界、流形边、投影不重叠及有限验证/索引预算。独立道路可传`terrainTopology`选择；共享terrainSupport消费者无需重复选择。`references/terrain-roads.md`和工具/核心接力索引写明输入条件、预算、共享所有权与明确限制。

验证：受影响`terrain-roads.test.mjs`在r187为26/26通过；语法、`git diff --check`及五份相关Markdown本地链接通过。完整Node回归在受限浏览器环境下773/791通过，唯一18项Chrome导出用例随后在正常启动权限下18/18通过，合并为791/791。此工具只证明支承消费者能读取非规则输入并生成道路，不证明C1约束地形生成器、旧道路保形、完整世界接入或视觉提升。
